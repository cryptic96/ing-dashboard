## Phase Goal

ROADMAP goal (verbatim): A tagged release deploys itself to the homelab LXC through a pipeline that cannot leak secrets. The running platform (app, PostgreSQL, Prometheus and Grafana) is locked down and ready to hold financial data before any real bank data arrives.

This plan is the supply-chain gate slice: after it, every push is built, tested and scanned, and a mutable action reference, a shell-injected expression, a leaked secret or a piece of personal data fails CI.

<objective>
Create one lint entry point (build/lint.sh) that runs digest-pinned actionlint, zizmor, shellcheck and gitleaks plus repository rules, identically on a developer machine and in CI; a CI workflow that builds, tests (PostgreSQL service container, per D-13) and lints every push; and Dependabot configuration that keeps action SHAs, NuGet packages and scanner images current.

Purpose: SEC-09 and SEC-10 must be enforced by CI before the release workflow exists, so the release workflow is born compliant; SEC-08's "GitHub-hosted runners only" is enforced statically here.
Output: build/lint.sh with checks and self-test fixtures, zizmor and gitleaks configuration, ci.yml, dependabot.yml.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| third-party actions → CI runner | Action code executes with the job's token |
| repository content → public | Everything committed is world-readable, forever, including history |
| scanner images → CI runner | Container images run against the checkout |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | third-party actions | high | mitigate | zizmor hash-pin policy for every action, self-tests prove short SHAs and tags fail, Dependabot keeps SHAs current |
| T-02-02 | Elevation of Privilege | run: steps | high | mitigate | zizmor template-injection and actionlint; self-test fixture proves an interpolated expression fails; values reach shell only via env: |
| T-02-03 | Information Disclosure | repository history | high | mitigate | gitleaks over full history and working tree with default rules; shallow clones refused; planted-secret self-test |
| T-02-04 | Information Disclosure | personal data in repo | high | mitigate | Custom rules for Dutch IBANs, RFC 1918 addresses and non-example email addresses; self-tests prove adjacency (RFC 5737 and example.com pass, private ranges fail) |
| T-02-05 | Elevation of Privilege | GITHUB_TOKEN | medium | mitigate | Top-level permissions {}, jobs contents: read, persist-credentials false |
| T-02-06 | Tampering | scanner images | medium | mitigate | Images pinned by digest in compose.yaml, updated by Dependabot docker-compose ecosystem |
| T-02-07 | Tampering | CI PostgreSQL service image | low | accept | Test-only container with no secrets and no network exposure beyond the job; pinned by digest, bumped manually because Dependabot does not update workflow service images |
| T-02-SC | Tampering | NuGet restore in CI | high | mitigate | restore --locked-mode through the package script against committed lock files |
</threat_model>
