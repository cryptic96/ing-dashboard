## Phase Goal

ROADMAP goal (verbatim): A tagged release deploys itself to the homelab LXC through a pipeline that cannot leak secrets. The running platform (app, PostgreSQL, Prometheus and Grafana) is locked down and ready to hold financial data before any real bank data arrives.

This plan is the platform bring-up: after it, GitHub enforces the release gates and the real LXC is provisioned, locked down and proven by selfcheck, ready for the first release.

<objective>
Have the operator apply the GitHub-side controls (D-01 tag ruleset, D-02 deploy environment reviewer, SEC-08 outside-contributor approval and GitHub-hosted-only execution, SEC-10 secret scanning and push protection) and build the LXC (D-06 pct create plus provision.sh, D-11 local roles, D-16 key custody, D-20 Traefik and DNS, D-21 Grafana accounts). Claude verifies the GitHub settings read-only with a reusable script, and the operator runs the on-host selfcheck.

Purpose: these controls cannot be expressed in repository files; they must exist before the first tag is pushed.
Output: build/check-github-settings.sh, a configured repository, a provisioned LXC.
</objective>
