## Phase Goal

ROADMAP goal (verbatim): A tagged release deploys itself to the homelab LXC through a pipeline that cannot leak secrets. The running platform (app, PostgreSQL, Prometheus and Grafana) is locked down and ready to hold financial data before any real bank data arrives.

This plan is the LXC half of the spine: after it, a published release is pulled, proven, migrated, activated and health-checked by a root installer that holds no GitHub credential.

<objective>
Write the root-owned installer (D-03) and its systemd units: an unauthenticated poll (D-02), download by tag, offline attestation verification with the release's Sigstore bundle before unpacking, an attested-commit-on-main check, downgrade refusal with an explicit rollback subcommand, pre-migration backup and migration bundle as the migrator OS user (OPS-07), side-by-side releases with an atomic current symlink and automatic rollback unless a migration ran (D-04), provisioning-file installation, health checks, and outcome reporting by email and textfile metrics (D-05).

Purpose: SEC-07's "server verifies the attestation before deploying" and SEC-08's "no GitHub-executed code runs on the server" live here.
Output: deploy/bin/ledger-deploy, deploy/lib/common.sh, deploy/lib/deploy.sh, systemd units, tests, docs/deploy.md.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet (GitHub, Sigstore) → root installer | Downloaded bytes and API answers are untrusted until verified |
