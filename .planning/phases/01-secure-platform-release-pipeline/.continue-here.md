## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Real infrastructure values in .planning | `.planning/` is committed to a public repository. Real addresses, hostnames, emails or ctids must never be written here | advisory | Real values live only in the untracked local note `.git/gsd-orch/infra-notes.md`; use placeholders such as {ledger-lxc} and {traefik-host} in any committed file; gitleaks in `build/lint.sh` catches private IPs and emails |
| Orchestrator state in the session scratchpad | The session scratchpad was wiped mid-wave, deleting worktree manifests and the gsd-tools shim | advisory | Keep orchestrator state (manifests, shim) under `.git/gsd-orch/`, which is untracked and outside every worktree |
| Parallel executors editing REQUIREMENTS.md | Every wave with several plans produced checkbox conflicts in REQUIREMENTS.md at merge time | advisory | Resolve with `.git/gsd-orch/union-resolve.py` (keeps any side that marked a requirement complete), then commit the merge |
| Executor-reported fork base | One executor reported its final HEAD as `expected_base` | advisory | Record worktrees with the base the orchestrator captured, after checking `git merge-base` |
| Local-green but CI-red | A network test passed locally but failed on CI, where the lint job exports GH_TOKEN | advisory | Before pushing lint-affecting changes, also run `GH_TOKEN=dummy LEDGER_LINT_NETWORK=1 build/lint.sh` |
| Host-only failures | Provisioning passed every logic test but failed on the real host (postgres OS user could not read SQL files under /root) | advisory | Treat the first real-host run as a test; fix in the repo, push, `git pull` on the host, re-run |
