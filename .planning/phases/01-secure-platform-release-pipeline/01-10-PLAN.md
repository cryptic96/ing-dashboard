## Phase Goal

ROADMAP goal (verbatim): A tagged release deploys itself to the homelab LXC through a pipeline that cannot leak secrets. The running platform (app, PostgreSQL, Prometheus and Grafana) is locked down and ready to hold financial data before any real bank data arrives.

This plan is the second provisioning slice: after it, provisioning brings every service up behind a default-drop firewall, creates the Grafana accounts, and one command on the LXC proves the whole platform is locked down; the setup guide covers every manual step.

<objective>
Finish provision.sh (D-06) with the services module (units, scripts, rendered server-side config, loopback-only Prometheus and node_exporter per D-23, age public key intake per D-16), the firewall module (D-20: only Traefik reaches the app and Grafana ports), and the Grafana accounts module (D-21: renamed admin, Viewer accounts via the HTTP API with typed passwords). Add ledger-selfcheck, the on-host acceptance script used in go-live, the Traefik route template with placeholders (D-20), and docs/lxc-setup.md covering every one-time step (OPS-03, D-12).

Purpose: OPS-03's "documented step by step", DASH-08's per-person viewer logins, DASH-09's LAN/VPN-only reachability and an automated way to prove SEC-02/SEC-05/SEC-08 on the real host.
Output: provision.d/40-60, service/config templates, ledger-selfcheck, Traefik template, setup guide.
</objective>
