## Phase Goal

ROADMAP goal (verbatim): After linking the ING accounts once, the household's real transactions arrive in the ledger every day. They are complete and never duplicated, bank-consent expiry never goes unnoticed, and both partners can see the data arriving.

This plan hardens the host before its first high-value secrets arrive (the aggregator key and the bank session) and gives the operator a safe way to create the aggregator key on the host itself, so the key never travels.

<objective>
Complete the folded "harden privileged units and scan logs for secrets" todo and prepare the aggregator key custody chosen under Claude's discretion (key generated once on the host under /etc/ledger, path in the env file, a copy in the password manager, excluded from backups like the Data Protection certificate). The key is stored password-protected, matching how the existing Data Protection certificate is protected, so the aggregator key is encrypted at rest.

Purpose: the linking flow needs the aggregator key; the selfcheck must catch any secret that leaks into logs, including the new bank key material.
Output: extended ledger-selfcheck with offline tests, sandboxed poll unit and apikey wrapper, tzdata in provisioning, new ledger-bank-key helper with offline tests, a docs section.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| application and services → journal and /var/log | A secret written to a log would persist outside the env file |
| root installer → host filesystem | The poll timer runs the installer as root on every poll |
| operator shell → ledger-bank-key → /etc/ledger | Generates and stores the aggregator key and its password |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-03-01 | Information Disclosure | secrets in logs | high | mitigate | check_log_secrets scans the journal and /var/log for every secret shape and value; FAIL output names only the kind and location |
| T-02-03-02 | Information Disclosure | needles in process arguments | medium | mitigate | Fixed-string needles fed through /dev/fd/3; openssl passwords via env:, never argv |
| T-02-03-03 | Elevation of Privilege | root installer unit | medium | mitigate | ProtectSystem=strict with a derived ReadWritePaths list, NoNewPrivileges, kernel/cgroup/namespace protection; live systemd-analyze check at go-live |
