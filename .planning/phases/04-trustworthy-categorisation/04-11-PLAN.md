## Phase Goal

ROADMAP goal (verbatim): Every transaction is correctly categorised: automatically by rules where they are confident, and by Claude and the user for the rest. Every change is audited and reversible, and the household can see where the money goes and how that compares with before.

The ROADMAP goal line is not written as a user story, so none is invented here.

This plan's slice: Claude can show what changed recently: which client did what, when, to how many objects, and whether it was undone. Undo through the same tools follows in plan 04-13.

Introduce one shared list of expected tools for the surface and scope tests so each tool added by the following plans of this phase touches one test file.

Purpose: ADV-06's "every change is visible".
Output: AuditService, AuditTools (recent_changes), AuditResults, ExpectedTools, tests.
</objective>
