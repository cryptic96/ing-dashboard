## Phase Goal

ROADMAP goal (verbatim): Every transaction is correctly categorised: automatically by rules where they are confident, and by Claude and the user for the rest. Every change is audited and reversible, and the household can see where the money goes and how that compares with before.

The ROADMAP goal line is not written as a user story, so none is invented here.

This plan's slice: the household tells Claude "that was concert tickets", and Claude records it as a short note on the transaction: audited, undoable, cleaned, and visible in Grafana. Claude reads it back in search results through plan 04-25.

<objective>
Add the household note, the one annotation this phase builds (D-28), written through the audited pipeline as a single-transaction write without confirmation (D-21), cleaned, capped and refused when instruction-like (D-23 second-order defence), and shown in reporting.transactions.

Purpose: ADV-06 (audited, undoable) and ADV-07 (stored text cannot carry an injection) for notes.
Output: transaction_notes, migration AddTransactionNotes, SetNoteAsync with NoteAuditHandler, change_ledger action set_note, NoteTests.
</objective>
