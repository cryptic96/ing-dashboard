## Phase Goal

ROADMAP goal (verbatim): Every transaction is correctly categorised: automatically by rules where they are confident, and by Claude and the user for the rest. Every change is audited and reversible, and the household can see where the money goes and how that compares with before.

The ROADMAP goal line is not written as a user story, so none is invented here.

This plan's slice: Claude receives bank text only as clearly wrapped, cleaned and capped data, and is told so on connection and in every tool that returns it. Flagging instruction-like text at sync follows in plan 04-20.

<objective>
Mark bank text as untrusted in full (D-23, no light version): a structured untrusted_bank_text wrapper in every read result (search, totals, counterparties), cleaning, masking and caps through UntrustedText, and server instructions and tool descriptions that say the text is data.

Purpose: ADV-07's untrusted-marking half for the existing read tools; the queue and overview tools of plans 04-28 and 04-30 follow the same wrapper.
Output: UntrustedFields, wrapped results, new ServerInstructions text, updated tests.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-15-01 | Tampering | prompt injection through descriptions and names | critical | mitigate | Structured untrusted wrapper, notice, instructions and descriptions; writes need explicit ids, the write scope and, for bulk, the user's confirmation (plans 04-09, 04-16) |
| T-04-15-02 | Tampering | invisible or bidirectional characters hiding text | high | mitigate | UntrustedText.Clean on every bank string; integration test |
| T-04-15-03 | Denial of Service | oversized bank text inflating tool results | medium | mitigate | Caps of 140 and 280 text elements with truncated flag |
| T-04-15-04 | Information Disclosure | account numbers in descriptions | high | mitigate | Masking before the cap |
| T-04-15-05 | Denial of Service | instructions truncated by the client | low | mitigate | 2,000-character test on instructions and descriptions |
