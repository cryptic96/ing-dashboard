## Phase Goal

ROADMAP goal (verbatim): Every transaction is correctly categorised: automatically by rules where they are confident, and by Claude and the user for the rest. Every change is audited and reversible, and the household can see where the money goes and how that compares with before.

The ROADMAP goal line is not written as a user story, so none is invented here.

This plan's slice: Claude can ask "how much did we spend on household expenses" or "show the uncategorised payments" and get totals and rows for that category including everything beneath it. Grouping by category and the instructions follow in plan 04-29.

<objective>
Make money_totals and search_transactions filter by category at any depth (D-01) and by "uncategorised" (D-09 provenance makes unassigned explicit), keeping transfers excluded unless the filter itself selects a transfer-kind node (D-16), with cursors bound to the filter.

Purpose: CAT-01 and CAT-04 for Claude's existing read tools.
Output: filter fields, store predicates, service resolution, tool parameters, tests.
</objective>
