## Phase Goal

ROADMAP goal (verbatim): Every transaction is correctly categorised: automatically by rules where they are confident, and by Claude and the user for the rest. Every change is audited and reversible, and the household can see where the money goes and how that compares with before.

The ROADMAP goal line is not written as a user story, so none is invented here.

This plan's slice: a payment whose description tries to instruct Claude is flagged at sync, counted for the operator, visible to Grafana, and reading it through any tool writes nothing.

<objective>
Flag instruction-like bank text at each sync and count it (D-24), expose the flag to Grafana, and prove with a synthetic hostile description that reading bank text through every read tool, with a write-scoped connection, changes nothing (D-23).

Purpose: ADV-07's "a test transaction whose description contains an instruction triggers no write".
Output: transaction_text_checks, migration AddTextChecks, text-check step in the engine, ledger_suspicious_bank_text_flagged_total, InjectedBankTextTests.
</objective>
