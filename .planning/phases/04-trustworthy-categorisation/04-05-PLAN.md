## Phase Goal

ROADMAP goal (verbatim): Every transaction is correctly categorised: automatically by rules where they are confident, and by Claude and the user for the rest. Every change is audited and reversible, and the household can see where the money goes and how that compares with before.

The ROADMAP goal line is not written as a user story, so none is invented here.

This plan's slice: the pure decision "assign with this rule, or queue for this reason" for any transaction against any rule set, built test first; the sync engine (04-17), the review queue (04-28) and rule previews (04-34) all call it.

<objective>
Implement RuleMatcher, RuleSpecificity and the rule records test first: explicit criteria only (D-11), the most specific rule wins (D-12), conflicts and intermediaries without a second signal go to the queue (D-07, D-15), fixed confidence meanings (D-09).

Purpose: CAT-03's matching rules and CAT-05's queue decision in one pure place.
Output: RuleModels, RuleSpecificity, RuleMatcher, RuleMatcherTests.
</objective>
