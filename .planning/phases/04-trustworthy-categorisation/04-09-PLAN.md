## Phase Goal

ROADMAP goal (verbatim): Every transaction is correctly categorised: automatically by rules where they are confident, and by Claude and the user for the rest. Every change is audited and reversible, and the household can see where the money goes and how that compares with before.

The ROADMAP goal line is not written as a user story, so none is invented here.

This plan's slice: writing needs a second consent. The user approves write access on the consent page; read-only connections, including the existing Claude Code grant, never see a write tool.

<objective>
Add the ledger.write OAuth scope (research Open Question 1, adopted), grant it only through the consent page, advertise it, and gate every write tool type with an mcp-write policy that hides the tools from read-only tokens and refuses their calls.

Purpose: ADV-07's "write tools act only for clients the user allowed to write"; the confirmation of individual bulk writes follows in plans 04-14 to 04-22.
Output: WriteScope, consent wording, mcp-write policy, test infrastructure for write connections, WriteScopeTests.
</objective>
