## Phase Goal

ROADMAP goal (verbatim): Every transaction is correctly categorised: automatically by rules where they are confident, and by Claude and the user for the rest. Every change is audited and reversible, and the household can see where the money goes and how that compares with before.

The ROADMAP goal line is not written as a user story, so none is invented here.

This plan's slice: Grafana's read-only role can query category roll-ups at any depth, the review status and the recent changes from views that add up and expose nothing sensitive. The Spending dashboard is built on them in plans 04-35, 04-38, 04-41 and 04-42.

Purpose: DASH-02's data contract.
Output: migration AddSpendingReportingViews, privilege matrix entries, SpendingSeed, SpendingViewsTests.
</objective>
