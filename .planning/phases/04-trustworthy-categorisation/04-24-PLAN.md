## Phase Goal

ROADMAP goal (verbatim): Every transaction is correctly categorised: automatically by rules where they are confident, and by Claude and the user for the rest. Every change is audited and reversible, and the household can see where the money goes and how that compares with before.

The ROADMAP goal line is not written as a user story, so none is invented here.

This plan's slice: Claude can see the household's whole category tree with both names and how many transactions sit on and beneath each node, the basis for proposing refinements (plans 04-26 and 04-37).

<objective>
Give Claude a read view of the category structure, category_overview: the any-depth tree (D-01) with English and Dutch names (D-03), kinds and counts per node, plus the uncategorised count.

Purpose: CAT-08's "based on the household's actual transactions" starts with seeing them per node.
Output: ICategoryStore.ReadOverviewAsync, CategoryOverviewService, CategoryTools (category_overview), CategoryResults, CategoryOverviewTests.
</objective>
