## Phase Goal

ROADMAP goal (verbatim): Every transaction is correctly categorised: automatically by rules where they are confident, and by Claude and the user for the rest. Every change is audited and reversible, and the household can see where the money goes and how that compares with before.

The ROADMAP goal line is not written as a user story, so none is invented here.

This plan's slice: after every sync, transfers between the household's synced accounts land in the Transfers band automatically, without touching anything the user decided and without failing the sync. Plan 04-12 then switches every total from the account-number test to the category kind.

<objective>
Add the automatic categorisation engine that runs after each account's ingestion, starting with the built-in transfer pass (D-16, building on the earlier synced-account rule; kind per D-06), never overwriting user decisions (D-13), never auditing automatic writes (D-29), keeping partner flows out of the Transfers band (D-18), and failing safely.

Purpose: CAT-02's detection half; the rule pass (04-17) and the text check (04-20) join the same engine.
Output: IAutoCategorisationStore, AutoCategorisationStore, CategorisationEngine, CategorisationMetrics, SyncOrchestrator hook, tests.
</objective>
