## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Merge helper refuses intended deletions | `worktree.cleanup-wave` blocks a branch that deletes a file (`branch_contains_deletions`), e.g. the planned rename of SignInPageHeadersMiddleware.cs | advisory | Check `git diff --name-status <base> <branch>` for D/R lines; if the deletion is a reported, intended rename, merge with `git merge --no-ff` and remove the worktree and branch by hand |
| Parallel full-suite runs exhaust Postgres connections | Two worktrees running the full suite against the shared local container hit "too many clients" (fixed partly by a 5 s idle lifetime in DatabaseFixture) | advisory | Run the orchestrator's post-merge gate only after all executors in the wave are done; do not launch a full suite while executors are testing |
| "Fail closed" that actually fails open | Returning null for an unreadable authenticator key made Identity complete a password-only sign-in | advisory | Every fail-closed claim on an auth path needs a test that drives the real sign-in flow to the refusal |
