## Phase Goal

ROADMAP goal (verbatim): Claude can answer accurate "how much" and "what did we spend" questions from the household's real transactions, on desktop, in Claude Code and on claude.ai web and mobile, through a securely exposed MCP endpoint.

After this plan the operator signs in with a password plus a one-time code (D-04), and the app itself enforces the public boundary (D-02, D-05, D-06 app side, SEC-04) even if a Traefik rule is wrong.

<objective>
Add the second factor with a replay guard, harden the sign-in and consent pages, and make the app enforce every boundary the public hostname relies on: host and path allow-list, home/VPN-only sign-in, canonical audience, scheme separation, hosted-client redirect, rate and size limits, no outbound calls, fail-fast production configuration and log redaction.

Purpose: the endpoint is about to become the host's first internet-facing surface; the app must stand on its own if the proxy configuration drifts.
Output: TOTP page and replay store, page headers, PublicHostGuard, RequestLimits, validator rules, env example keys, unit and integration tests.
</objective>
