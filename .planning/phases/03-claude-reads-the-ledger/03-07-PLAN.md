## Phase Goal

ROADMAP goal (verbatim): Claude can answer accurate "how much" and "what did we spend" questions from the household's real transactions, on desktop, in Claude Code and on claude.ai web and mobile, through a securely exposed MCP endpoint.

After this plan Claude Code on the home network answers questions from the real ledger through the deployed endpoint, which is reachable from home and VPN only. This is the first proof with a real Claude client; the public exposure follows in the next plan, after Claude's temporary SSH access is removed (folded todo).

Purpose: catch any real-client incompatibility (issuer form, resource form, stateless mode, scopes) before anything is public.
Output: a merged and deployed release, a configured host, LAN-only routes, an enrolled login and a working Claude Code connection; no repository files change.

## Addendum (2026-10-08, before execution)

Changes made after this plan was written (pre-release code review fixes, quick tasks 261007-vrj and 261008-0av) alter Task 2's operator sequence. Where they conflict, this addendum wins.

1. **Port 5080 now serves HTTPS** with a host-generated certificate (`/etc/ledger/backend-tls.crt`, public; `/etc/ledger/backend-tls.key`, secret) and Traefik must reach it through the pinned `ledger-backend` serversTransport. The installer on the host comes from provisioning, not from the release, and v0.3.0 migrates (no automatic rollback). Therefore, per `docs/lxc-setup.md` "Upgrading a host that has no certificate yet":
   - After the PR is merged and `v0.3.0` is tagged, but **before approving the deploy environment**, the operator checks out the tag on the ledger host and re-runs `./deploy/provision.sh` (creates the certificate, installs the new installer, selfcheck, `ledger-login` and `ledger-grants`). This replaces old step 2.
   - Claude prepares the updated route file (REST/MCP service on `https://<ledger>:5080` with the inline public certificate; MCP routers on the home/VPN allowlist) but saves it on the proxy only right after the installer reports success. Claude may read the public certificate and its fingerprint; never the key.
   - Expect a short bad-gateway window for the REST API between install and saving the route; Grafana is unaffected.
2. **`ledger-login confirm-totp NAME`** now asks for the code at a hidden prompt (or stdin); the code is no longer an argument (old step 5).
3. **Selfcheck** now also verifies the TLS handshake on 5080 presents exactly the certificate on disk, refuses plain HTTP, and warns 30 days before expiry; all its 5080 probes use the pinned certificate.
4. **Migrations in v0.3.0:** `AddOAuthAndLogins` and `TrackLastTotpTimeStep`; Task 1's manifest check should find both.
5. **DNS:** the MCP hostname's certificate is issued by the proxy's existing DNS-challenge resolver, so the public `A` record is not needed in this plan; create only the local record now and the public record in the go-live plan (old step 4).
6. The operator approved opening the PR to main (never merge or tag).
