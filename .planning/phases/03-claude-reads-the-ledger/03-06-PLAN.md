## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet -> Traefik routers | The template decides what the internet can reach |
| DNS (public and local) -> clients | The hostname must resolve publicly to the home IPv4 address and locally to Traefik |
| operator workstation -> host via SSH | The temporary Claude login is checked for by the selfcheck |
