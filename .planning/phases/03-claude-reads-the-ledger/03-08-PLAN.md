ROADMAP goal (verbatim): Claude can answer accurate "how much" and "what did we spend" questions from the household's real transactions, on desktop, in Claude Code and on claude.ai web and mobile, through a securely exposed MCP endpoint.

After this plan the goal is met: claude.ai on the web, the mobile app and Claude Desktop answer from the real ledger through the public, OAuth-protected endpoint, which answers only Anthropic's range for the public paths and only home and VPN for sign-in (ROADMAP success criteria 1 and 5).

Purpose: the public step is taken only on a host nobody but the operator can administer, with the boundary proven from both sides.
Output: SSH access removed, public route live, claude.ai connected, docs/mcp.md updated with observed behaviour, the SSH todo closed.
</objective>
