## Phase Goal

ROADMAP goal (verbatim): Claude can answer accurate "how much" and "what did we spend" questions from the household's real transactions, on desktop, in Claude Code and on claude.ai web and mobile, through a securely exposed MCP endpoint.

After this plan the operator can enrol a login on the host, cut every Claude connection off with one command, and is told by email when tokens are being rejected, a new connection is approved or a refresh token is reused (D-07).

<objective>
Give the operator the controls a public endpoint needs: the ledger-login enrolment CLI (D-01, D-04), the ledger-grants kill switch (D-07), MCP and token metrics with opaque labels, and three access alerts through the existing contact point.

Purpose: the operator must be able to see and stop access without the web app and without Claude.
Output: two CLI commands with sandboxed wrappers, a revocation service, OpenIddict event handlers, metrics, alert rules with lint and expression tests, monitoring docs, tests.
</objective>
