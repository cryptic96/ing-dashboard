## Phase Goal

ROADMAP goal (verbatim): Claude can answer accurate "how much" and "what did we spend" questions from the household's real transactions, on desktop, in Claude Code and on claude.ai web and mobile, through a securely exposed MCP endpoint.

After this plan Claude can show what the household spent on (search) and find how merchants are spelled (counterparties), under a hard cap that always says when it truncated (ROADMAP success criterion 4), with the complete four-tool surface.

<objective>
Add search_transactions (keyset pagination, cap, truncation notice; ADV-03) and find_counterparties (spelling lookup for filters; D-08), mask counterparty account numbers (D-14), and lock down the tool surface: exactly four intent-shaped read-only tools (ADV-01), instructions that route every total to money_totals (Pitfall 9), and no tool argument in logs.

Purpose: totals need supporting detail and correct filters; detail must never become Claude's arithmetic or an unbounded dump.
Output: cursor, store queries, service results, two tools, instruction updates, unit and integration tests.
</objective>
